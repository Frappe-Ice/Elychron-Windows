# Elychron Windows 个人可用版

## 目标

Windows 主程序保留 Elychron 的完整待办能力，并针对桌面交互调整导航、窗口和通知；
桌面挂件只负责展示今日课程与日程，并可跳转到主程序详情。

当前版本首先服务单个用户和固定设备，优先保证日常可用性，不把商店发布、签名和大范围兼容
作为前置条件。

## 第一阶段验收闭环

1. Windows 上能够启动现有 Elychron 主程序。
2. 日程、待办、专注、学业、设置五个主页面均可通过桌面侧边栏进入。
3. 待办能够新建、编辑、完成、恢复和删除；四种时间语义与子待办保持可用。
4. 本地数据在重启后仍存在，并能正常导入、导出。
5. 桌面挂件能够展示当天课程、考试和有时间的待办，包括从学业模块自动导入的新作业。
6. 点击挂件条目能够唤起主程序；复杂编辑始终在主程序内完成。
7. 手机与 Windows 至少有一种可靠的手动同步方式，之后再升级自动同步。

## 暂不作为阻塞项

- Microsoft Store、MSIX 签名、安装器和自动更新。
- Windows Widgets Board 官方小组件。
- 对所有 Windows 版本和硬件的兼容验证。
- PTA 数据源。
- 面向公众发布所需的引导、遥测、隐私页面和发布流水线。

## 技术边界

- 现有 Dart 模型和待办页面是唯一业务实现，Windows 不复制一套待办逻辑。
- Windows 专属能力通过小型原生桥接实现；Flutter 继续承载主界面。
- 桌面挂件只读取版本化的只读 JSON 快照，不直接打开 Hive 数据库。
- 账号、密码、Cookie 和 AI Key 不进入跨设备同步包。
