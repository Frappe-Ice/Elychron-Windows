Elychron Windows 便携版
======================

使用方法
--------
1. 请先完整解压压缩包，不要直接在压缩软件中运行。
2. 双击 Elychron.exe 打开主窗口。
3. “设置 > Windows”中可以：
   - 开启或关闭桌面挂件随 Windows 启动；
   - 创建或更新桌面快捷方式；
   - 手动打开桌面挂件；
   - 查看并触发学业、PTA 等来源的同步。

登录记忆与隐私
--------------
- 安装包不含任何账号、密码、Cookie、课表、待办、日志或个人路径。
- 登录后，账号凭据由 Windows 安全存储保护；PTA 登录状态和应用数据保存在
  当前 Windows 用户自己的 AppData 中，不写入本目录。
- 因此更新或移动程序目录不会主动清除登录状态；其他用户拿到这个压缩包也
  不会得到本机的任何个人信息。

开机自启动
----------
- 首次运行后，Elychron 默认注册“桌面挂件”开机启动项，只打开挂件，不弹出
  主窗口。
- 移动 Elychron 文件夹后，请重新运行一次 Elychron.exe，让启动项自动指向
  新位置；桌面快捷方式也应在“设置 > Windows”中重新创建。
- 若不需要自启动，可在“设置 > Windows”中关闭。

运行要求
--------
- Windows 10 或 Windows 11（64 位）。
- PTA 登录页面依赖 Microsoft Edge WebView2 Runtime；现代 Windows 通常已自带。
- 浙江大学相关数据源需要能访问相应校园服务；按实际情况连接校园网或 VPN。
